# Между страницами — библиотека Мари

Адаптивный сайт-макет читательского дневника с 416 произведениями.

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий `mari-library`.
2. Загрузите `index.html`, папку `data` и `.nojekyll` в корень ветки `main`.
3. Откройте **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.
4. После публикации сайт появится на `https://julskazka.github.io/mari-library/` (если репозиторий создан в аккаунте julskazka).

## ВАЖНО О СОХРАНЕНИИ

Это статическая демоверсия. Новые книги и отзывы сохраняются только в `localStorage` браузера, НЕ в GitHub. При смене устройства они не перенесутся, а при очистке данных браузера могут пропасть. Перед внесением постоянных записей нужно реализовать защищённое сохранение и резервное копирование.

В файле `data/mari-library-416-backup.json` — исходный архив данных на момент этой сборки. Содержимое файла и книги внутри HTML **публичны** при размещении в публичном репозитории. Не размещайте там приватные детские фотографии и личные заметки без отдельной защиты.
